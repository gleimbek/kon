# Kön Arquitectura

Website proposal for Kön Arquitectura, an architecture studio in Argentina. In Spanish.

**Live site:** https://gleimbek.github.io/kon/

## What it has

- **Projects** showing the studio's finished homes and works in progress, with real photos
- **Photo gallery** that opens each image in a larger view
- **Contact form** that checks every field, then writes the message and opens it in WhatsApp, addressed to the studio

## Built with

HTML, CSS and vanilla JavaScript, no frameworks or build step.

## Run locally

Open `index.html` in a browser.
